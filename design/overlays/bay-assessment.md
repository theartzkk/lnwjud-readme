# BAY Assessment Overlay

Assessment is an academic workflow under BAY EXCUSE X, not an owner-control surface.

- Primary navigation: ภาพรวม / ส่งข้อสอบ / ข้อสอบ / ตรวจข้อสอบ / ผลการสอบ. Advanced authoring and administration belongs under เพิ่มเติม.
- Exit returns to BAY academic context. It must not send teachers to AWH.
- Mobile primary navigation stays within five items and must not obscure content or scan controls.
- Scan, upload and long-running grading actions expose shared pressed/loading/success/error feedback.
- Use the KRUART light foundation; status colors are semantic only.
