# BAY Computer Lab Overlay

Computer Lab is the student entry surface. LearnLab is a learning destination reached from it.

- Student primary navigation: วันนี้ / งานของฉัน / คะแนน / LearnLab / เพิ่มเติม.
- Teacher and diagnostic utilities stay visually secondary and must not compete with student tasks.
- Teacher entry is labelled สำหรับครู and is compact on student/mobile surfaces.
- LearnLab handoff preserves the return context.
- Network state and long-running actions are announced with accessible live feedback.
- Touch targets are at least 44 px and bottom/sticky UI respects device safe areas.
