      เครื่องที่พร้อมทำงาน
      ดาวน์โหลด AWH Desktop

      AWH จะแสดงเฉพาะ installer ที่มี release identity และ checksum ตรวจสอบได้เท่านั้น
      

      
      MY AWH
      ความจำ ลักษณะ และข้อมูลของคุณ
      ข้อมูลส่วนตัวแยกจากความจำของโปรเจกต์ และ Source of Truth ปัจจุบันมีสิทธิ์เหนือความจำเสมอ
      ลักษณะของ AWH
      ส่งออกข้อมูลของฉัน
      ส่งออกทะเบียน โปรเจกต์ การสนทนา และการตั้งค่า โดยไม่รวมรหัสผ่าน ความลับ หรือไฟล์ source
      

      
      SYSTEM
      ระบบและฐานข้อมูล
      ดูแล AWH จากจุดเดียวโดยไม่ต้องแตะเครื่องมือซับซ้อน ส่วนฐานข้อมูลเปิดแบบอ่านอย่างปลอดภัยเป็นค่าเริ่มต้น
      ⌘Infrastructureดู VPS, Services, Projects, Domains, SSL, Backup, Security และ Deployments จากหน้าเดียว→▦Database Studioดูตาราง โครงสร้าง Migration สุขภาพระบบ และค้นข้อมูลอย่างปลอดภัย→
      AWH Control Plane
      ฐานข้อมูลจริงยังเป็น Source of Truth เดียวของ AWH และไม่สร้างฐานข้อมูลคู่ขนาน
      รายละเอียดสำหรับผู้ดูแลระบบ
      Database Studio ใช้ Owner session เดียวกับ AWH และบังคับ read-only/query-only พร้อมซ่อนตาราง credential โดยค่าเริ่มต้น
