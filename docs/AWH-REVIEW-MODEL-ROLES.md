# AWH Review Roles

Review is evidence, never Production authority. Deterministic QA, exact source/release evidence, visual verification, and Owner approval remain authoritative.

## Roles

| Role | Purpose |
| --- | --- |
| Primary UX/Product critic | Review screenshots, information architecture, copy, friction, and mental model |
| Visual second opinion | Independently compare mobile/desktop hierarchy and regression evidence |
| Architecture judge | Check proposed fixes against AWH authority and release constraints |
| Fast verification | Re-check resolved findings and small regressions |
| Research reviewer | Use current web evidence only when the review question actually requires it |

A reviewer may produce PASS, REVIEW, or BLOCK evidence, but cannot mutate source, deploy, change permissions, or become a parallel issue database.

Prefer visual-first evidence. Supply source snippets only when a finding needs implementation-level diagnosis.
