# AWH Durable Handoff

This file is intentionally short. Future agents must inspect the real repository, migrations, CI and production evidence before acting.

Permanent rules:
- AWH Cloud is the authority; personal devices are optional workers.
- One canonical user/project/memory/task/artifact identity; no parallel authority.
- Stable releases require verified backup, migration/rollback plans and green release gates.
- Desktop identity is stable and intended for install-once evergreen updates.
- Source of Truth beats remembered/chat context.
- Do not bypass production security gates, including SSH host-key verification.

Primary contracts: `config/awh-product-contract.json`, `docs/AWH_SUSTAINABILITY_CONTRACT.md`, `docs/RELEASE.md`, `docs/RECOVERY.md`, `docs/OPERATIONS.md`.
